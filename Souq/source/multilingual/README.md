## 1) كيف تُقرأ هذه الموسوعة؟

لا تبحث عن «كيف تُترجم يا هلا وسهلا». ابحث عن:

> **ماذا يقول بائع حقيقي في هذا الموقف، في هذه الثقافة، لهذا المخاطَب؟**

قد تكون العبارة العربية «هلا بالنشاما» بلا مقابل حرفي في الفرنسية. المقابل الطبيعي حينها ليس جملة غريبة، بل أسلوب الترحيب الرجولي الودود المستخدم فعليًا هناك — أو التصريح بأنه **لا يوجد مقابل مباشر**.

المسار التعليمي المقصود:

**الموقف → العبارة الأصلية → النطق التقريبي → المعنى بالعربية → لمن تُقال → متى تُقال → الحوار → القالب**

## 3) خريطة التصفح السريعة

**لغة → بيئة → وظيفة → عبارة**

- تركيا → Kapalıçarşı / pazar / mağaza → ترحيب → `Hoş geldiniz, buyurun`
- إندونيسيا → pasar / warung / mall → تفاوض على «mahal» → `Bisa kurang, Kak?` / رد البائع
- طاجيكستان → бозор / дӯкон → ضيافة الشاي → `Чой бинӯшед`
- فرنسا → boutique → دخول → `Bonjour Madame/Monsieur` (إلزامي ثقافيًا)
- سوق شعبي فرنكوفوني (مغرب/غرب أفريقيا) → مساومة أوسع → `Je vous fais un prix`
- بريطانيا → high street → مساعدة بلا ضغط → `I'll be right here if you need me`
- أمريكا → سلسلة → وداع → `Have a nice day` / `You're all set`
- سوق إنجليزي → مساومة → `That's as low as I can go`

## 4) البحث داخل الموسوعة

ابحث في الملفات أو في `phrases-ml.csv` بـ:

- العربية (`آخر سعر`, `غالي`, `تفضل`, `نورتونا`)
- النص الأصلي (`son fiyat`, `harga pas`, `нархи охирин`, `dernier prix`, `just browsing`)
- الوظيفة (`ترحيب`, `تفاوض`, `إغلاق`)
- اللغة / البلد / المخاطَب

عمود `arabic` في CSV يربط العبارة الأجنبية بنظيرتها العربية إن وُجدت.  
عمود `noDirectArabic` = عبارة أصيلة في تلك اللغة بلا مقابل عربي مباشر.

## 5) علاقة هذا المجلد بالموسوعة العربية

- الملفات 01–15 و`phrases-db.csv` **لم تُمس** من حيث محتواها العربي.
- التصنيف الوظيفي **A–K** نفسه مستعمل هنا (جذب، ترحيب، عرض، تفاوض…).
- رموز الشيوع نفسها: 🔥 ⭐ ✅ 🟡 ⚪ ⚠️
- سلم الرسمية نفسه (1 رسمي جدًا … 6 حميمي).
- أُضيف سلم **ثقة المصدر** الخاص باللغات الأجنبية: عالية / متوسطة / منخفضة.

## 6) ما ليس موجودًا في المشروع (بصراحة)

هذا المستودع **موسوعة محتوى** (Markdown + CSV)، لا تطبيق واجهة بعد. لذلك:

- لا يوجد محرك بحث تفاعلي ولا مفضلة تقنية — المفضلة تكون يدويًا أو عبر CSV.
- لا يوجد مشغّل صوت؛ النطق مكتوب تقريبًا بالعربية مع التنبيه أنه تقريبي.
- إن بُنيت واجهة لاحقًا: الحقول في `phrases-ml.csv` جاهزة للتصفية حسب اللغة → البلد → الفئة → الموقف.

لا تكسر الموسوعة العربية ولا تستبدلها. هذه طبقة موازية أغنى من الترجمة.
