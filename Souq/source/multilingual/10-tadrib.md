# تمارين مواقف — ليست قاموسًا

> درّب **القرار** لا الحفظ: الموقف → لمن تتكلم → أي سجل → أي عبارة.  
> الإجابات النموذجية في ملفات اللغات؛ هنا نختبر الاختيار.

---

## 1) اختر العبارة المناسبة (وليست الترجمة)

**س1.** زبون دخل محل ملابس في باريس ولم تسلّم. ما أكبر خطأ؟  
أ) لم تعرض المنتج فورًا  
ب) لم تقل **Bonjour**  
ج) لم تسأله عن المقاس  
→ **ب** (قاعدة اجتماعية أقوى من أي عرض)

**س2.** تريد معنى «بس شوف، ما بتخسر شيء» في إندونيسيا. أيها الحي؟  
أ) Anda tidak akan kehilangan apa pun jika melihat  
ب) **Lihat dulu, nggak wajib beli**  
ج) Silakan mengobservasi barang dagangan  
→ **ب**

**س3.** زبون تركي يقول لك وأنت البائع: **Kolay gelsin**. ماذا يفعل؟  
أ) يطلب خصمًا  
ب) يودّعك بغضب  
ج) **يبارك شغلك** (يقوله الزبون عادةً)  
→ **ج** — لا مقابل عربي مباشر بنفس الشيوع

**س4.** زبونة غريبة في دوشنبه. أي نداء أسلم؟  
أ) Ҷонам  
ب) **Хонум / Апа**  
ج) Девушка بصوت عالٍ  
→ **ب**

**س5.** «هلا بالنشاما» في الفرنسية. الصحيح:  
أ) Ô homme courageux !  
ب) **لا مقابل حرفي؛ قل Monsieur + ترحيب حار أو مدح الذوق لا الرجولة**  
ج) Hala les nachamas  
→ **ب**

**س6.** زبون في لندن قال `Just browsing`. ماذا تفعل؟  
أ) تكرر Can I help you؟ حتى يشتري  
ب) **Take your time — I'll be right here if you need me**  
ج) Why come in if you're not buying?  
→ **ب**

**س7.** «نورتونا» بالإنجليزية. الصحيح:  
أ) You have illuminated the shop  
ب) **Welcome in / Good to see you (للدائم)**  
ج) Light upon us  
→ **ب**

## 2) مطابقة «غالي»

الزبون قال إن السعر غالي. صلّ الرد باستراتيجيته:

| الرد | اللغة | الاستراتيجية |
|---|---|---|
| Pahalı değil, kaliteli | تركية | إعادة تأطير |
| Saya tunjukkan yang lebih hemat | إندونيسية | بديل أرخص |
| Яке арзонтар нишон диҳам | طاجيكية | بديل أرخص |
| Je vous montre une gamme plus douce | فرنسية | بديل أرخص |
| Rugi saya, Kak | إندونيسية | رفض النزول بأني المتضرر |
| Je vous fais un geste | فرنسية | خصم صغير مسموح |
| That's as low as I can go | إنجليزية سوق | نزول أخير |
| Let me show you another price range | إنجليزية محل | بديل بلا مساومة |

تمرين: اكتب ردّين لكل لغة: (1) لا أنزل، أبيّن الجودة (2) أنزل بشرط كمية.

## 3) لعب أدوار (بائع ↔ زبون)

نفّذ الحوار كاملًا بصوت عالٍ. لا تقرأ الترجمة أولًا.

1. **أتفرج فقط** — من `07-hiwarat.md` الحوار 1 بلغتك المختارة.  
2. **غالي ثم اتفاق** — الحوار 2.  
3. **دائم عاد** — الحوار 4.  
4. **غاضب وعيب** — الحوار 7. غيّر المنتج (عطر / جوال / حذاء).

معيار النجاح: اخترت اللقب الصحيح، وما ضغطت بعد «أتفرج»، وما قلت ما يعادل «غالي عليك».

---

## 4) رتّب خطوات الصفقة

ضع الأرقام بالترتيب الصحيح لكل بيئة:

**بازار تركي (سجاد):**  
( ) Son fiyat  
( ) Hoş geldiniz + Çay?  
( ) Buyurun bakın  
( ) Paketleyeyim mi?  
( ) Yine bekleriz / Güle güle kullanın  

الترتيب النموذجي: ترحيب وشاي → انظر → (حديث وجودة) → مساومة/آخر سعر → تغليف → وداع وتهنئة استخدام.

**محل فرنسي في مول:**  
( ) Bonjour Madame  
( ) Je peux vous aider ?  
( ) Je vous laisse regarder  
( ) C’est le prix affiché  
( ) Je vous l’emballe ?  
( ) Merci, bonne journée  

لا تُقحم المساومة بعد البطاقة.

**محل إنجليزي (هاي ستريت / مول):**  
( ) Hi there  
( ) Need any help? / I'll be right here  
( ) Just browsing → Take your time  
( ) That's the ticket price  
( ) Shall I wrap that?  
( ) Thanks for coming in — have a nice day

## 7) أخطاء صوّبها

1. في باريس: «Viens voir mon frère !» لزبون بدلة رسمية.  
   → خطأ: tu + نداء حميمي. الصحيح: **Bonjour Monsieur, je vous montre…**

2. في مول جاكرتا: «Mampir! Murah-murah!» من الممر.  
   → أسلوب pasar لا mall. الصحيح: **Selamat datang, ada yang bisa saya bantu?**

3. ترجمة «نورتونا» إلى الفرنسية: «Vous avez illuminé le magasin».  
   → غير طبيعية. الصحيح: **Quel plaisir de vous voir** أو Bonjour حار.

4. اختراع نداء موزون طاجيكي بلا مصدر والزعم أنه شائع.  
   → ممنوع حسب المنهج.

5. في مول أمريكي: «Come look! Cheap cheap!» من الممر.  
   → أسلوب بسطة لا سلسلة. الصحيح: **Hi there — let me know if you need anything.**
