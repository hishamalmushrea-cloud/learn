# القسم 24 — القوالب اللغوية القابلة لإعادة الاستخدام

> هذه أهم أداة عملية في الموسوعة: بدل حفظ مئات الجمل، احفظ **الهيكل** وبدّل الكلمات حسب المنتج والزبون واللهجة. كل قالب مع أمثلة تطبيقية.

---

## 1) قوالب الجذب (من الشارع/الباب)

1. **«يا ___، تعال شوف ___»** — يا (لقب)، تعال شوف (المنتج)
   - «يا أستاذ، تعال شوف الجديد» / «يا خويا، تعال شوف هادشي»
2. **«عندي لك ___ يمكن يعجبك»**
   - «عندي لك شي يمكن يعجبك» / «عندي ليك حاجة تجيك» (تونسية)
3. **«بس شوف، ما ___»** — بس شوف + طمأنة
   - «بس شوف، ما بتخسر شيء» / «بس شوف، ولا يلزمك شيء»
4. **«شوف ___ قبل ما ___»**
   - «شوف الجديد قبل ما تروح» / «شوف اللي عندنا قبل ما تشتري من غيرنا»
5. **«دقيقة وحدة، عندي ___»**
   - «دقيقة وحدة، عندي شيء على ذوقك»
6. **«اليوم عندنا ___»** — مفاجأة اليوم
   - «اليوم عندنا حراج» / «اليوم عندنا بضاعة جديدة»
7. **«___ وصل اليوم»**
   - «الجديد وصل اليوم» / «أول الكمية وصل اليوم»
8. **«هذا اللي ___»** — إثبات اجتماعي
   - «هذا اللي الكل يدور عليه» / «هذا اللي عليه طلب»

## 2) قوالب الترحيب

9. **«يا هلا ___»**
   - «يا هلا وسهلا» / «يا هلا بالغالي» / «يا هلا بالعيلة»
10. **«___ نورت/نورتونا»**
    - «نورت المحل» / «نورتونا، منورين»
11. **«تفضل/تفضلي ___»** — دعوة الدخول
    - «تفضل، شو بدك؟» / «تفضلي، خذي راحتك»
12. **«حياك الله، ___»**
    - «حياك الله، تفضل» / «حياكم الله، اتفضلوا»
13. **«البيت/المحل ___»** — الضيافة
    - «البيت بيتك» / «المحل بيتك» / «الدكان بيتك» (خليجية/عراقية)
14. **«كيفك؟ ___»** — ترحيب + سؤال
    - «كيفك؟ شو بدك اليوم؟» / «شلونك؟ شكو ماكو؟» (عراقية)

## 3) قوالب اكتشاف الحاجة

15. **«بتدور على ___؟»**
    - «بتدور على شيء معين؟» / «بتدور على هدية؟»
16. **«لمين ___؟»**
    - «لمين؟ لنفسك ولا هدية؟» / «لمين الحذاء؟»
17. **«بأي مناسبة ___؟»**
    - «بأي مناسبة؟ عيد؟ زواج؟»
18. **«تحب ___ ولا ___؟»** — اختيار ثنائي
    - «تحب الغامق ولا الفاتح؟» / «تحب الأرخص ولا الأفضل؟»
19. **«عندك ___ معين ببالك؟»**
    - «عندك موديل معين ببالك؟» / «عندك سعر معين ببالك؟»

## 4) قوالب عرض المنتج

20. **«شوف ___»** — الأبسط
    - «شوف هذا» / «شوف اللي عندنا» / «شوف بنفسك»
21. **«تعال أوريك ___»**
    - «تعال أوريك شيء» / «تعال أوريك التشكيلة الجديدة»
22. **«هذا ___»** + صفة
    - «هذا جديد» / «هذا آخر موديل» / «هذا أصلًا» / «هذا عليه طلب»
23. **«عندنا ___»**
    - «عندنا شغلات حلوة» / «عندنا كل المقاسات» / «عندنا الأصلي»
24. **«خذها بإيدك، ___»** — تجربة حسية
    - «خذها بإيدك، حس على الخامة» / «جربها، شوف الراحة»
25. **«هذا يصلح لـ ___»** — تخصيص
    - «هذا يصلح للدوام» / «هذا يناسب البنات الصغار»
26. **«الفرق بينهم ___»** — مقارنة
    - «الفرق بينهم عشرين ريال، والزيادة تستاهل»

## 5) قوالب تعزيز القيمة

27. **«ميزته إنه ___»**
    - «ميزته إنه يتحمل» / «ميزته إنه موفر»
28. **«حسبك: ___»** — تقسيم التكلفة
    - «حسبك إذا قسمتها على سنين» / «حسبك يوميًا، تطلع بلا قيمة»
29. **«الرخيص ___ والغالي ___»** — تأطير
    - «الرخيص يندمك، والغالي يخدمك» / «غالي مرة ولا رخيص مرتين»
30. **«مضمون، وإذا ___»** — ضمان
    - «مضمون، وإذا في عيب نبدله» / «جرّب، وإذا ما عجبك ارجعه»
31. **«الناس ___»** — إثبات اجتماعي
    - «الناس تسأل عنه كثير» / «الناس ترجع تشتريه مرة ثانية»
32. **«آخر ___ عندنا»** — ندرة
    - «آخر قطعة» / «آخر كمية» / «آخر لون»

## 6) قوالب التفاوض والخصم

33. **«عشانك، ___»** — الخصم الشخصي
    - «عشانك، أنا أنزلها» / «عشانك، أحسبها لك حسبة حلوة»
34. **«لك خصم إذا ___»** — خصم مشروط
    - «لك خصم إذا أخذت قطعتين» / «لك خصم إذا دفعت كاش»
35. **«خلني أشوف لك ___»**
    - «خلني أشوف لك سعر أحسن» / «خلني أشوف لك شي أنسب»
36. **«إذا أخذت ___ أعطيك ___»**
    - «إذا أخذت أكثر، أعطيك سعر الجملة» / «إذا أخذت 10، أعطيك وحدة هدية»
37. **«آخر ___»** — النهاية
    - «آخر سعر» / «آخر كلام» / «آخر سومة»
38. **«بس عشان خاطر ___»**
    - «بس عشان خاطر عيونك» / «بس عشان خاطر زيارتك»
39. **«قول ___ ونشوف»** — عكس المساومة
    - «قول كم يدك ونشوف» / «سومني وشوفنا»
40. **«ما أقدر أنزل، بس أقدر ___»** — بديل عن الخصم
    - «ما أقدر أنزل، بس أقدر أضيف لك هدية» / «ما أقدر، بس أبعثه لك توصيل مجاني»

## 7) قوالب الرد على الاعتراضات

41. **«غالي؟ شوف ___»**
    - «غالي؟ شوف الجودة أول» / «غالي؟ قارنه بغيره»
42. **«يمكن، بس ___»** — اعتراف + تحويل
    - «يمكن، بس الفرق في الضمان» / «يمكن، بس هذا يدوم أكثر»
43. **«طبيعي ___، بس ___»** — تطبيع التردد
    - «طبيعي تفكر، بس خذ كل المعلومة» / «طبيعي الواحد يتأكد»
44. **«تمام، ___»** — قبول ثم بذرة
    - «تمام، بس خذ رقمي» / «تمام، بس جرب قبل ما تقرر»
45. **«إذا ما عجبك، ___»** — إزالة الخوف
    - «إذا ما عجبك، ارجعه» / «إذا ما عجبك، نبدله لك»

## 8) قوالب البيع الإضافي

46. **«خذ معها ___ — يكملها»**
    - «خذ معها الحزام — يكملها» / «خذ معاه الغطا — يكملها»
47. **«كثير ياخذون ___ مع ___»**
    - «كثير ياخذون الاثنين مع بعض» / «كثير ياخذون القميص مع البنطلون»
48. **«بس تزيد شوي، تاخذ ___»** — ترقية
    - «بس تزيد شوي، تاخذ الأفضل» / «بس تزيد 10، تاخذ الكبير»
49. **«لأنك أخذت ___، أعطيك ___»**
    - «لأنك أخذت هذا، أعطيك الثاني بخصم»
50. **«نجمعها لك ___»** — تجميع
    - «نجمعها لك بحسبة حلوة» / «نجمعها لك بسعر واحد»

## 9) قوالب إغلاق البيع

51. **«ن___ لك؟»** — افتراض الإغلاق
    - «نغلفها لك؟» / «نحسبها لك؟» / «نوصلهالك؟»
52. **«تاخذ ___ ولا ___؟»** — إغلاق باختيارين
    - «تاخذ الأولى ولا الثانية؟» / «تاخذها اليوم ولا بكرة؟»
53. **«خلاص، ___؟»** — تثبيت
    - «خلاص، اتفقنا؟» / «خلاص، صارت صفقة؟»
54. **«أنا واثق إنك ___»**
    - «أنا واثق إنك بترجع تشكرني» / «أنا واثق إنها بتعجبك»

## 10) قوالب الوداع والمحافظة

55. **«نورت، ___»**
    - «نورت، نستناك دايمًا» / «نورت، المحل بيتك»
56. **«مرة ثانية، ___»**
    - «مرة ثانية، وعلى خير» / «مرة ثانية، مع الجديد»
57. **«إذا احتجت ___، إحنا هنا»**
    - «إذا احتجت أي شي، إحنا هنا» / «إذا احتجت مقاس ثاني، رجعلنا»
58. **«سلملي على ___»**
    - «سلملي على العيلة» / «سلملي على صحابك — وجيبهم معك»
59. **«بكرة عندنا ___ — تعال»**
    - «بكرة عندنا بضاعة جديدة — تعال» / «بكرة العرض — لا تفوتك»
60. **«خذ رقمنا/بطاقتنا ___»**
    - «خذ رقمنا — إذا وصل جديد نكلمك»
