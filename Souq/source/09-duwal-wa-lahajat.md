# القسمان 22–23 — لغة التاجر في كل دولة عربية + الفروق بين اللهجات

> ⚠️ تنبيه منهجي: هذه الملامح مبنية على مصادر مكتوبة وملاحظة عامة، وليست حكمًا نهائيًا على "كل تاجر" في أي بلد. داخل كل دولة اختلافات مدينة/قرية/جيل/نوع محل. كل عبارة هنا وُضعت بعد تحقق نسبي؛ والموسومة بـ"تحتاج تحققًا" يجب اختبارها ميدانيًا.

---

## 1) السعودية (نجد، حجاز، شرق، جنوب)

**السمات:** الكرم اللفظي عالٍ ("البيت بيتك")، الاحترام بـ"يا أخوي/يا الغالي/يا طويل العمر"، المساومة اسمها **"المكاسرة"** (حجازًا) وهي "تواصل اجتماعي لطيف لا إهانة فيه" [مصدر: مقال مصطلحات مكة والمدينة]، والبيع بـ"يتعامل" (الزبون يتعامل مع البائع = يساوم) [مصدر: دليل اللهجة السعودية].

| الوظيفة | العبارة |
|---|---|
| الترحيب | «يا هلا وسهلا، نورت.» 🔥 / «حيّاك الله.» 🔥 |
| الجذب | «يا أخوي، تعال شوف الجديد.» 🔥 |
| السؤال عن السعر (من الزبون) | «بيش؟ بكم؟ شكد سعره؟» 🔥 [مصدر: دليل اللهجة السعودية] |
| طلب تخفيض | «خفّض لنا شوي» / «قللنا من السعر» / «بكم تخليها؟» ⭐ |
| إعطاء خصم | «عشانك، أنا أنزلها.» 🔥 |
| آخر سعر | «آخر سعر، ما فيه كلام.» ⭐ |
| ألقاب | «يا نشمي» (نجد)، «يا أخوي»، «يا طويل العمر»، «يا حج» (للحاج) |
| المزاح | «تبيها بلاش؟ خذ المحل كمان.» ⭐ |
| الوداع | «تساهيل» (أقل شيوعًا من عمان)، «في أمان الله» |
| ملاحظة | سوق "الحراج" و"الزل" و"البطحاء" أسواق شعبية تشتهر بالمكاسرة [مصدر: دليل الأسواق الشعبية السعودية] |

## 2) اليمن

**السمات:** لغة ضيافة عريقة، "الحراج" اليمني (سوق المزايدة) ظاهرة خاصة، القات والبخور والمندي محلات لها لغة خاصة، والنداء بـ"يا حاج/يا شيخ/يا أخ".

| الوظيفة | العبارة |
|---|---|
| الترحيب | «أهلًا وسهلًا، أهلاً بيك.» 🔥 / «يا هلا بالضيف.» ⭐ |
| الجذب | «تعال شوف — عندنا اليوم شيء زين.» ⭐ |
| السؤال عن السعر | «بشكم هذا؟» 🔥 (بشكم = بكم) / «كم حقه؟» |
| المساومة | «خفضه شوي — الله يبارك فيك.» ⭐ |
| آخر سعر | «آخر كلام، والله ما أقدر أنزل.» ⭐ |
| السوق | «الحراج» = مزايدة علنية: «من يزيد؟ من يزيد؟» ⭐ |
| ألقاب | «يا شيخ» (احترام)، «يا أخ»، «يا حاج» |
| ملاحظة | القهوة جزء من الضيافة التجارية: «تفضل، اشرب قهوة» في محلات البخور والعسل |

## 3) الأردن

**السمات:** لغة شامية دافئة، "يا هلا" و"تفضل"، والسؤال الشهير "شو بتحب؟/شو بدك؟"، والمساومة "قديش؟/أديش؟" — الود محترم، والمزاح خفيف مع الدائمين.

| الوظيفة | العبارة |
|---|---|
| الترحيب | «أهلين وسهلين، يا هلا.» 🔥 |
| الجذب | «يا أستاذ، تعال شوف — في شي بيعجبك.» ⭐ |
| السؤال عن السعر | «قديش هذا؟» / «أديش؟» 🔥 |
| المساومة | «زود شوي، أنا بنزل لك.» / «خلينا نتوصل.» ⭐ |
| خصم | «عشانك يا غالي، بستاهلك.» ⭐ |
| ألقاب | «يا معلم»، «يا خوي»، «يا زلمة» (بين الأقران)، «يا عم» (للكبير) |
| الوداع | «الله معك، نورتنا.» ⭐ |

## 4) فلسطين

**السمات:** قريبة من الأردنية؛ دفء عالٍ، "يا هلا" و"يعطيك العافية"، وأسواق المدن القديمة (الخليل، نابلس، القدس) فيها تراث بيع عريق: الخليل تشتهر بالخزف والزجاج، ونابلس بالصابون والحلويات، والباعة يستقبلون بـ"تفضل يا أستاذ يا مهندس" [مصدر: تقرير باعة غزة].

| الوظيفة | العبارة |
|---|---|
| الترحيب | «يا هلا والله، نورت.» 🔥 |
| الجذب | «الكعك يا حبايب، جديد وسخن!» ⭐ (نداء بائع كعك) |
| السؤال عن السعر | «قديش؟ / أديش؟ / بكم؟» 🔥 |
| خصم | «بس عشانك، بستاهلك يا غالي.» ⭐ |
| الوداع | «الله يخليك، وترجع بالسلامة.» ⭐ |
| ملاحظة | الباعة في غزة والضفة يمزحون مع الأطفال: «كيف المدرسة اليوم؟» [مصدر: وكالة معًا] |

## 5) سوريا

**السمات:** لغة حوارية غنية، "يا هلا فيك" و"شو بتحب؟"، والسؤال "قديش؟"، والنداء "يا خيي" (أخي)، وكثرة الدعاء: "الله يخليك"، "يعطيك العافية".

| الوظيفة | العبارة |
|---|---|
| الترحيب | «يا هلا فيك، تفضل.» 🔥 |
| الجذب | «تعال شوف — في شي حلو نازل جديد.» ⭐ |
| السؤال عن السعر | «قديش؟ / بكم؟» 🔥 |
| المساومة | «خلينا نتوصل — أنا ما بغلّي.» ⭐ |
| خصم | «لك خصم — بس ما تحكي لأحد.» ⭐ |
| ألقاب | «يا خيي»، «يا عمي» (للكبير)، «يا معلم»، «يا حبيبي» |
| الوداع | «الله معك، نورتنا.» ⭐ |
| ملاحظة | في أسواق دمشق وحلب القديمة (الحميدية، المدينة) الباعة يخاطبون الزبون بـ"يا حج" أحيانًا احترامًا |

## 6) العراق

**السمات:** "يا حجي" لقب التاجر والزبون معًا، "شكو ماكو" ترحيب، "شكثر؟" للسعر، و"خوش" للمدح، و"ولك" للنداء (⚠️ "ولك" قد تُعد مستهانة في سياقات — انظر المصادر) [مصدر: منتديات اللهجة العراقية].

| الوظيفة | العبارة |
|---|---|
| الترحيب | «هلا والله، شلونك؟ شكو ماكو؟» 🔥 |
| الجذب | «يا حجي، تعال شوف — عندي خوش شي.» 🔥 |
| السؤال عن السعر | «شكثر هذا؟ / بكم؟» 🔥 |
| المساومة | «زين، خليها عليك بكذا — بس لا تكسرني.» ⭐ |
| خصم | «عشانك يا حجي، ألك خصم.» ⭐ |
| ألقاب | «يا حجي» (للجميع)، «يا عمي» (احترام)، «يا زلمة» |
| الوداع | «هلا بيك، عيني، كل وقت.» ⭐ |
| ملاحظة | "شكو ماكو" وحدها كفيلة بفتح أي حوار عراقي؛ وتُفهم مرحبًا في عموم العراق [مصدر: منتديات عراقية] |

## 7) الكويت

**السمات:** ترحيب "يا هلا والله" و"نورت"، و"شنو تبي؟"، والمساومة في الأسواق الشعبية (سوق المباركية) بأسلوب مرح، والألقاب "يا الغالي/يا بطل/يا أخوي".

| الوظيفة | العبارة |
|---|---|
| الترحيب | «يا هلا والله، نورتنا.» 🔥 |
| الجذب | «يا أخوي، شوف الجديد — وصل اليوم.» ⭐ |
| السؤال عن السعر | «بكم؟ شنو سعره؟» 🔥 |
| المساومة | «شنو تسوم؟» (ما هو عرضك؟) ✅ |
| خصم | «عشانك، أحسبها لك حسبة حلوة.» ⭐ |
| الوداع | «تسلم، نورتنا — نستناك.» ⭐ |

## 8) الإمارات

**السمات:** مزيج تراثي حديث؛ أسواق ديرة والطابق الأرضي في دبي تحافظ على المساومة، مع لغة رسمية ودودة في المولات. "يا هلا" و"تفضل" و"بكم؟".

| الوظيفة | العبارة |
|---|---|
| الترحيب | «يا هلا، أهلاً وسهلاً.» 🔥 |
| الجذب | «تفضل شوف — عندنا الذهب الجديد.» ⭐ (في أسواق الذهب) |
| السؤال عن السعر | «بكم هذا؟ / كم سعره؟» 🔥 |
| المساومة | «السعر على كلامنا — تعال نتفاهم.» ⭐ |
| خصم | «لك خصم اليوم — عشانك.» ⭐ |
| ملاحظة | في أسواق الذهب: البيع على "المصنعية" — «نحسب لك الذهب بسعره + المصنعية بسيطة.» ✅ |

## 9) قطر

**السمات:** لغة خليجية هادئة مهذبة؛ "يا هلا" و"حياك الله" و"تفضل"، والأسواق الشعبية (سوق واقف) تجمع المساومة والضيافة.

| الوظيفة | العبارة |
|---|---|
| الترحيب | «حياك الله، يا هلا.» 🔥 |
| الجذب | «يا طويل العمر، تعال شوف.» ⭐ |
| السؤال عن السعر | «بكم؟» 🔥 |
| المساومة | «قلناها ونحنا سوا — خذها بسعر طيب.» ⭐ |
| الوداع | «الله يسلمك، في أمان الله.» ⭐ |

## 10) البحرين

**السمات:** أسواق المنامة الشعبية (سوق المنامة القديم) لغة خليجية حارة؛ "يا هلا" و"تفضل"، ومساومة مرحة.

| الوظيفة | العبارة |
|---|---|
| الترحيب | «يا هلا والله، نورت.» 🔥 |
| الجذب | «عندنا الجديد — تعال شوف قبل ما يخلص.» ⭐ |
| السؤال عن السعر | «بكم؟» 🔥 |
| خصم | «عشان خاطر عيونك، أنزلها.» ⭐ |
| الوداع | «تسلم، نستناك دايمًا.» ⭐ |

## 11) عُمان

**السمات:** لغة مهذبة فيها "تساهيل" الترحيبية الشهيرة، وأسواق نزوى وصلالة ومطرح لها طابع ضيافة قوي؛ البخور والفضة العمانية لها لغة بيع خاصة.

| الوظيفة | العبارة |
|---|---|
| الترحيب | «أهلاً وسهلاً، تساهيل.» 🔥 |
| الجذب | «تفضل، شوف البخور الأصلي — من ظفار.» ⭐ |
| السؤال عن السعر | «بكم؟ / شحال؟» 🟡 ("شحال" تُسمع في عمان أيضًا) |
| المساومة | «سومة طيبة، ونحن نتيسر.» ✅ |
| الوداع | «تساهيل، وفي أمان الله.» ⭐ |
| ملاحظة | "تساهيل" تُقال ترحيبًا ووداعًا — من أطرف الفروق اللغوية العمانية [تحتاج تحققًا ميدانيًا لانتشارها] |

## 12) مصر

**السمات:** أغنى تراث نداءات في العالم العربي (انظر ملف 02: "بعشرة وبس"، "حمار وحلاوة")، سلم ألقاب فخم (باشا/بيه/فندم/معلم/حج/ست/مدام)، ومساومة "كام؟/بكام؟" و"آخر كلام".

| الوظيفة | العبارة |
|---|---|
| الترحيب | «أهلًا، تفضل يا باشا/يا فندم.» 🔥 |
| الجذب | «بكام؟ لأ، خد شوف الأول — عندنا الجديد.» ⭐ |
| السؤال عن السعر | «بكام دي؟ / كام؟» 🔥 |
| المساومة | «خفف شوية — ده كتير عليا.» (من الزبون) / «قول انت: تدفع كام؟» (من البائع) |
| خصم | «عشان خاطرك، بستاهلك — خدها بكذا.» 🔥 |
| آخر سعر | «ده آخر كلام — والله ما فيش بعده.» 🔥 |
| ألقاب | «يا باشا/يا بيه/يا فندم/يا معلم/يا حج/يا عم» (رجال) — «يا مدام/يا هانم/يا ست/يا حاجة/يا آنسة» (نساء) |
| الوداع | «ربنا معاك، نورت — تعالى تاني.» ⭐ |
| ملاحظة | "يا باشمهندس" مجاملة مهنية شهيرة؛ والباعة الجائلون يغنّون نداءاتهم [مصادر: عدة تقارير] |

## 13) السودان

**السمات:** "يا زول" نداء الود، "بكم ده؟" للسعر، ودعاء "الله يبارك"، وأسواق أمدرمان والخرطوم الشعبية فيها لغة حوارية موسيقية.

| الوظيفة | العبارة |
|---|---|
| الترحيب | «أهلًا وسهلًا، كيفك؟» 🔥 |
| الجذب | «يا زول، تعال شوف — عندنا الحاجة الزات.» ⭐ |
| السؤال عن السعر | «بكم ده؟» 🔥 |
| المساومة | «خفف علينا — الله يبارك فيك.» ⭐ |
| خصم | «عشانك، بس ما تزعلني.» ⭐ |
| ألقاب | «يا زول» (ودّي)، «يا حاج» (احترام) |
| ملاحظة | "زات" = جدًا/نفسه: «حلو زات» — تدخل في مدح البضاعة [تحتاج تحققًا ميدانيًا] |

## 14) ليبيا

**السمات:** لغة مغاربية فيها "يا زلمة" و"يا خوي"، و"شحال/قداش" للسعر، وأسواق طرابلس وبنغازي القديمة.

| الوظيفة | العبارة |
|---|---|
| الترحيب | «أهلًا وسهلًا، تفضل.» 🔥 |
| الجذب | «يا زلمة، تعال شوف — عندي حاجة زينة.» ⭐ |
| السؤال عن السعر | «شحال؟ / قداش؟» 🔥 |
| المساومة | «نقص شوية — نتوافقو.» ⭐ |
| خصم | «عشانك يا خوي، نحسبوها باهية.» ⭐ |
| ألقاب | «يا زلمة»، «يا خوي»، «يا معلم» |
| ملاحظة | تحتاج تحققًا ميدانيًا للتفاصيل الدقيقة — المصادر المكتوبة عن اللهجة الليبية التجارية محدودة |

## 15) تونس

**السمات:** "قداش؟" للسعر، و"سوم/سومني" لعرض السعر، و"برشا أهلًا" للترحيب، و"يعيشك" للشكر، والأسواق العتيقة (سوق تونس، سوسة) فيها مساومة فنية.

| الوظيفة | العبارة |
|---|---|
| الترحيب | «أهلًا، برشا أهلًا بيك.» 🔥 |
| الجذب | «تعال شوف — عندي حاجة تجيك.» ⭐ |
| السؤال عن السعر | «قداش هذا؟» 🔥 |
| المساومة | «سومني — نشوفو.» 🔥 (اعرض عليّ سعرًا) |
| خصم | «خليها عليك — عيشك.» ⭐ |
| آخر سعر | «هذا آخر سومة.» ⭐ |
| ألقاب | «يا سي فلان» (احترام)، «يا خويا»، «يا ولدي» (من الكبير للشاب) |
| الوداع | «يعيشك، الله يخليك.» ⭐ |

## 16) الجزائر

**السمات:** "قداش/قداه؟" و"شحال؟" معًا، و"يا خويا" النداء الأشمل، و"صحيت" للشكر، و"برك" (كفاية) في المساومة، وأسواق القصبة وقسنطينة.

| الوظيفة | العبارة |
|---|---|
| الترحيب | «أهلًا وسهلًا، تفضل يا خويا.» 🔥 |
| الجذب | «عندي ليك حاجة تخدمك — تعال شوف.» ⭐ |
| السؤال عن السعر | «قداش؟ / شحال؟» 🔥 |
| المساومة | «برك! ما نقدرش — هذا الثمن نتاع الجودة.» ⭐ |
| خصم | «على خاطرك، نحسبهالك مزيان.» ⭐ |
| ألقاب | «يا خويا»، «يا وليدي» (من الكبير للشاب)، «يا سي» |
| الوداع | «صحيت، ربي يخليك.» ⭐ |

## 17) المغرب

**السمات:** المساومة اسمها **"التشطار"** [مصدر: دليل التسوق بالدارجة المغربية]، و"شحال؟" للسعر، و"واخا" للموافقة، و"يا خويا" للنداء، وأسواق مراكش وفاس (جامع الفنا، المدينة القديمة) من أشهر أسواق المساومة عالميًا.

| الوظيفة | العبارة |
|---|---|
| الترحيب | «مرحبا، مرحبتين، أهلًا.» 🔥 |
| الجذب | «يا خويا، شوف هادشي — جاي يعجبك.» 🔥 |
| السؤال عن السعر | «شحال هادشي؟ / بشحال؟» 🔥 [مصدر: دليل التسوق المغربي] |
| المساومة | «نقص شوية» / «صاوب شوية» / «شحال تخلي لي؟» 🔥 [مصدر: نفسه] |
| خصم | «على خاطرك، نعطيك الثمن ديالي.» ⭐ |
| آخر سعر | «هذا آخر ثمن — والله.» ⭐ |
| ألقاب | «يا خويا»، «يا صاحبي»، «يا ولدي/يا بنتي» (من الكبير)، «يا سي»، «يا لالا» (نساء) |
| الوداع | «الله يعطيك الصحة، سير بالسلامة.» ⭐ |
| ملاحظة | من أشهر جمل الزبون المغربي في المساومة: «الله يرحم الوالدين» — نداء البركة — يرد البائع غالبًا بخصم رمزي |

## 18) موريتانيا

**السمات:** الحسانية (العربية الموريتانية)؛ "لبيه" للتلبية، و"شحال/بكم" للسعر، وأسواق نواكشوط (السوق المركزي) والبيرات في الصحراء.

| الوظيفة | العبارة |
|---|---|
| الترحيب | «أهلًا وسهلًا، كيف الحال؟» 🔥 |

| السؤال عن السعر | «شحال؟ / بكم؟» 🔥 |
| التلبية | «لبيه.» 🔥 (أنا في خدمتك) |
| المساومة | «نقص ليا — الله يبارك فيك.» ⭐ |
| ألقاب | «يا أخي»، «يا وليد» (شاب) |
| ملاحظة | تحتاج تحققًا ميدانيًا — المصادر المكتوبة المتاحة محدودة |

## القسم 23 — المقارنات بين اللهجات (جداول)

### 23.1 "بكم هذا؟" — كيف يسأل الزبون عن السعر؟

| المنطقة | الصيغة | أمثلة |
|---|---|---|
| الخليج (سعودية/كويت/قطر/إمارات/بحرين) | بكم؟ / شكد؟ / بيش؟ | «بكم هذا؟» 🔥 |
| عمان | بكم؟ (وأحيانًا شحال؟) | «بكم؟» 🔥 |
| اليمن | بشكم؟ | «بشكم هذا؟» 🔥 |
| الشام (سوريا/لبنان) | قديش؟ / بكم؟ | «قديش؟» 🔥 |
| الأردن/فلسطين | قديش؟ / أديش؟ | «أديش هذا؟» 🔥 |
| العراق | شكثر؟ / بكم؟ | «شكثر؟» 🔥 |
| مصر | بكام؟ / كام؟ | «بكام دي؟» 🔥 |
| السودان | بكم ده؟ | «بكم ده؟» 🔥 |
| المغرب | شحال؟ / بشحال؟ | «شحال هادشي؟» 🔥 |
| الجزائر/تونس | قداش؟ / شحال؟ | «قداش هذا؟» 🔥 |
| ليبيا | شحال؟ / قداش؟ | «شحال؟» ⭐ |
| موريتانيا | شحال؟ / بكم؟ | «شحال؟» ⭐ |

### 23.2 "آخر سعر" — كيف يقول البائع النهاية؟

- مشتركة: «آخر سعر» 🔥 / «آخر كلام» ⭐
- مصر: «ده آخر كلام» ⭐
- تونس/خليج: «آخر سومة» ⭐
- مغرب: «هذا آخر ثمن» ⭐
- عراق: «هذا آخر شي» ✅

### 23.3 "أبشر" وأخواتها (قبول الطلب)

- خليج/عراق: «أبشر» 🔥 — من "بشّر" أي أُبشرك بالخير: سأفعل.
- شام/مصر: «حاضر» / «تحت أمرك» 🔥
- مغرب: «واخا» 🔥 (موافقة)
- تونس: «يحياك» ✅
- موريتانيا: «لبيه» 🔥
- مشتركة: «ولا يهمك» 🔥 / «من عيوني» 🔥 (خليج/شام وتُفهم في كل مكان)

### 23.4 "غالي" — كيف يتفاعل البائع معها؟

- الخليج: «غالي؟ شوف الجودة أول.» / «والله سعرنا طيب.» ⭐
- الشام: «غالي؟ معك حق، بس هلأ الجودة كلها غالية.» ⭐
- مصر: «غالي؟ ده سعره قدامك — بص على الشغل.» ⭐
- المغرب: «غالي؟ شحال بغيتي تخلص؟» (كم تريد أن تدفع؟) ⭐
- العراق: «غالي؟ خوش شي دايمًا غالي.» ⭐ — "الجيد غالٍ" رد عراقي مرح

### 23.5 أسلوب المزاح في كل منطقة (مقارنة)

| المنطقة | طابع المزاح التجاري |
|---|---|
| الخليج | مبالغة كرمية: «تاخذها بلاش؟ المحل كله لك» + قسم "عشان خاطرك" |
| الشام | سخرية لطيفة من النفس: «أنا غلطان إني فتحت المحل اليوم» |
| مصر | نكتة سريعة ومقفّاة: «إيدك على البضاعة = البضاعة ملكك» |
| العراق | "دايخ" مرح: «ولك، تريدها هدية؟» مع ضحكة عالية |
| المغرب العربي | مساومة مسرحية: التمسرح بالأسعار والبركة («الله يرحم الوالدين») |
| عمان/اليمن | هدوء وكرم: المزاح أقل والضيافة أكثر |

### 23.6 درجة الرسمية والاحترام (خلاصة)

- **الأكثر رسمية في اللقب**: مصر (باشا/فندم/هانم/مدام) والمغرب (سي/مولاي) والعراق (حجي/عمي).
- **الأكثر ألفة سريعة**: السودان (زول)، المغرب (خويا)، الخليج (أخوي/غالي).
- **الأكثر كرمًا لفظيًا**: الخليج واليمن ("البيت بيتك").
- **الأكثر دعاءً في الكلام**: الشام ومصر والمغرب (الله يخليك/يعطيك العافية/صحيت/ربي يبارك).
- **الأقل ميلًا للمساومة**: المتاجر الحديثة في كل الدول (أسعار مثبتة) مقابل الأسواق الشعبية (مساومة متوقعة).

## القسم 32 — المدينة والقرية والسوق الشعبي (فروق داخل البلد الواحد)

| البيئة | لغة البائع | أمثلة |
|---|---|---|
| مركز المدينة (تجاري) | مهذبة، أسرع، أقرب للرسمية | «تفضل، كيف أساعدك؟» |
| الحي الشعبي | دافئة، ألفة سريعة، مساومة | «يا ابن الحي، تعال — سعرك غير.» ⭐ |
| السوق الشعبي | أعلى صوت، نداءات، مساومة كاملة | «يا ناس! اليوم حراج!» |
| السوق الفاخر/المول | رسمية، لا مساومة، خدمة | «أهلًا وسهلًا، تحت أمركم.» |
| القرية | أبطأ، شخصية، علاقة عائلية | «يا أهلًا — إنت ابن فلان، خذها بسعر.» |
| المناطق القبلية (خليج/يمن) | احترام مضاعف، كرم، "العرض" (الضيافة القبلية) | «أنت ضيفنا — ولا كلام في السعر.» |
| السوق السياحي | لغة مزدوجة (عربي + إنجليزي)، أسعار مفتوحة | «Welcome! لك سعر خاص.» |
