# موسوعة السوق

تطبيق ويب عربي مستقل (PWA) يعمل بدون إنترنت.  
هذا المجلد **مشروع قائم بذاته**: انسخه كما هو إلى فرع أو مستودع جديد، ولا يحتاج IndoLearn ولا بقية مستودع `learn`.

## التشغيل

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

ثم افتح العنوان الذي يعطيه الخادم. لا تفتح `index.html` مباشرة من الملفات — عامل الخدمة والبحث يحتاجان خادماً.

## نسخ المجلد إلى فرع جديد

من جهازك، داخل مستودع `learn`:

```bash
git fetch origin
git checkout arena/01a01a73-learn

# فرع جديد محتواه = هذا المجلد فقط
git subtree split -P Souq -b souq-app
git push origin souq-app
```

أو انسخ المجلد يدوياً إلى مستودع فارغ:

```bash
cp -R Souq /path/to/new-repo
cd /path/to/new-repo
git init
git add .
git commit -m "موسوعة السوق — تطبيق مستقل"
```

بعد `subtree split` تصبح ملفات التطبيق في **جذر الفرع** (`index.html` بجانب README). أوامر التشغيل نفسها.

## الميزات

- بحث شامل في الأقسام والعبارات واللغات
- قاعدة عبارات عربية مع فلترة (دولة / لهجة / موقف)
- تصنيف وظيفي (A–K)
- بوابة لغات + مقارنة الوظائف + حوارات تفاعلية
- زر **استمع** فوق العبارات والجمل (Web Speech)
- مفضلة، وضع ليلي، حجم خط، تثبيت كـ PWA
- يعمل دون إنترنت بعد أول تحميل
