# موسوعة السوق (Souq)

تطبيق ويب عربي مستقل (PWA) يعمل بدون إنترنت، يقدّم **موسوعة لغة السوق والبائع والزبون** بالكامل وبشكل منظّم وجميل وسهل القراءة.

> الموسوعة مأخوذة كما هي من مشروع [`seller`](https://github.com/hishamalmushrea-cloud/seller.git) — الفرع `arena/019ff95f-seller` — وأُضيفت كقسم/تطبيق جديد مستقل داخل هذا المستودع.

## ما الذي يحتويه التطبيق (بدون أي حذف)

- **15 قسماً** من الموسوعة (مبادئ اللغة، الجذب والترحيب، المخاطبة، العرض والإقناع، الخصم والتفاوض، المزاح، أنواع الزبائن، الأسواق، الدول واللهجات، القوالب، الحوارات، القاموس، التحذيرات، أفضل العبارات، المصادر).
- **337 عبارة وجملة** في **قاعدة العبارات** مع ترجمتها الفصحى ودولتها ولهجتها وموقفها — قابلة للبحث والفلترة.
- **نظرة عامة** عن المنهجية والرموز والمصادر.
- كل المحتوى مُضمَّن داخل التطبيق (لا يحتاج إنترنت).

## الميزات

- **بحث شامل** (🔍): يفتش في كل الأقسام *وقاعدة العبارات* معاً، مع خيار تحديد النطاق (كل شيء / أقسام فقط / عبارات فقط) وعرض مقتطفات من الأقسام.
- **بوابة التصنيف الوظيفي (A–K)**: تستخرج التصنيف الوظيفي من القسم ١، وتعرض كل وظيفة (لفت الانتباه، الترحيب، العرض، التفاوض، الإغلاق…) مع عباراتها المصنّفة والقسم المختص بها.
- **موسوعة متعددة اللغات**: خمس لغات (التركية 🇹🇷، الإندونيسية 🇮🇩، الطاجيكية 🇹🇯، الفرنسية 🇫🇷، الإنجليزية 🇬🇧) — منهجها، قوالبها، حواراتها، قاموسها، ومقارناتها (معادلات وظيفية وثقافية لا ترجمة حرفية).
- **قاعدة عبارات متعددة اللغات**: ٢٠٥ عبارة أصلية مع ترجمتها العربية ومعناها ونطقها التقريبي، قابلة للبحث والفلترة حسب اللغة/الوظيفة/الدولة.
- **مقارنة الوظائف**: نفس الموقف الاجتماعي يُعرض عبر اللغات الخمس جنباً إلى جنب في جدول واحد.
- تصفّح الأقسام مع **جدول محتويات** داخلي لكل قسم.
- **قاعدة عبارات** تفاعلية: بحث نصي + فلترة حسب الدولة/اللهجة/الموقف/المخاطَب.
- **المفضلة**: احفظ أي عبارة بنجمة ☆ وصدّرها.
- **الوضع الليلي**، **تغيير حجم الخط**، **التثبيت كتطبيق** على الجوال.
- تصميم عربي RTL متجاوب (جوال + سطح مكتب).

## البنية

```
Souq/
├── index.html            # هيكل التطبيق (RTL عربي)
├── manifest.json         # إعداد PWA
├── sw.js                 # عامل الخدمة (يعمل بدون إنترنت)
├── css/
│   ├── styles.css        # نظام التصميم (سمة ذهبية للسوق)
│   └── fonts/Cairo-Variable.ttf
├── js/
│   ├── data.js           # كل البيانات (مولّد تلقائياً)
│   └── app.js            # المنطق + محرّك الماركدون العربي
├── icons/                # أيقونات التطبيق (SVG)
├── source/               # المصادر الأصلية كما وردت من المشروع (للتحقق)
│   ├── 01-mabadi-wa-tasnif.md ... 15-masadir.md
│   ├── README.md
│   └── phrases-db.csv
└── tools/
    └── build_data.py     # يولّد js/data.js من المصادر
```

## التشغيل

افتح `index.html` عبر خادم ويب محلي (مثل):

```bash
cd Souq
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## إعادة توليد البيانات

إذا عدّلت ملفات `source/`، شغّل:

```bash
python3 tools/build_data.py
```

سيُعاد بناء `js/data.js` تلقائياً بكل الفصول والعبارات.
