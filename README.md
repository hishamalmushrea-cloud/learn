## التطبيقات

### 📱 IndoLearn
تطبيق Android لتعليم **الإندونيسية** و**التركية** للعرب (من الصفر إلى الاستخدام اليومي).
- الكود: `IndoLearn/`
- واجهة ويب مرجعية (PWA): `IndoLearn/app/src/main/assets/`

### 🏪 موسوعة السوق (Souq)
تطبيق ويب عربي **مستقل بالكامل** داخل المجلد `Souq/` — يُنسخ وحده إلى فرع أو مستودع جديد دون باقي هذا المستودع.
- 15 قسماً عربياً + 337 عبارة + طبقة بخمس لغات (205 عبارات)
- التفاصيل ونسخ الفرع: [`Souq/README.md`](Souq/README.md)
- التشغيل: `cd Souq && python3 -m http.server 8080`
