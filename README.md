# learn

مستودع منصّات تعلّم عربية. يحتوي على:

## التطبيقات

### 📱 IndoLearn
تطبيق Android لتعليم **الإندونيسية** و**التركية** للعرب (من الصفر إلى الاستخدام اليومي).
- الكود: `IndoLearn/`
- واجهة ويب مرجعية (PWA): `IndoLearn/app/src/main/assets/`

### 🏪 موسوعة السوق (Souq)
تطبيق ويب عربي مستقل (PWA) يعمل بدون إنترنت، يقدّم **موسوعة لغة السوق والبائع والزبون** بالكامل:
- 15 قسماً منظّماً (الجذب، الترحيب، العرض، الإقناع، المساومة، المزاح، أنواع الزبائن، الأسواق، اللهجات، القوالب، الحوارات، القاموس، التحذيرات، أفضل العبارات، المصادر).
- قاعدة عبارات تفاعلية (337 عبارة) مع بحث وفلترة.
- نظرة عامة عن المنهجية والمصادر.
- الكود: `Souq/`
- التشغيل: `cd Souq && python3 -m http.server 8080`

> الموسوعة مأخوذة من مشروع `seller` (الفرع `arena/019ff95f-seller`) وأُضيفت كتطبيق سوق جديد مستقل.

## أدوات التحقق
`tools/` يحتوي سكربتات للتحقق من المحتوى وبناء قواعد البيانات.
