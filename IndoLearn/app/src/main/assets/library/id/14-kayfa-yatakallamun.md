# الجزء 14. كيف يتكلم الإندونيسيون فعلًا؟

الكتب تعلّمك *Bahasa Indonesia yang baik dan benar*.  
الناس تتكلم *bahasa sehari-hari* مخلوطة أحيانًا بـ gaul وجاكرتا وجاوية.

هذا الباب للفهم أولًا. الإنتاج الانتقائي ثانيًا.

مصادر الطبقة الوصفية: ويكيبيديا Indonesian slang (مع التحفظ على التفاصيل غير المؤرخة)، ملاحظات Reddit للمتعلمين والمواطنين، قوائم gaul الصحفية 2024–2025، دراسة جسيمات UGM، ومقابلة الرسمي/اليومي في Wikipedia Indonesian language.

## 1. أربع عمليات تصنع «كلام الناس»

1. **استبدال كلمة:** tidak → nggak  
2. **اختصار صوت:** sudah → udah → dah  
3. **خلع لاصقة مع بقاء أثرها:** mengerti → ngerti  
4. **رمي جسيم في آخر الجملة:** mahal, sih · kasih, dong

إن أتقنت الأربع، تفهم 50٪ إضافية من الشارع.

## 3. الجسيمات — قلب «الإحساس»

دراسة UGM (Natural Semantic Metalanguage) ترصد على الأقل: ah, deh, dong, kan, kek, kok, lah, lho, sih, ya.

### ya
تليين، طلب موافقة، تأكيد.  
Tunggu, ya. · Ini 20 ribu, ya? · Ya, saya mau.

آمن جدًا. أنتجها.

### dong
«يعني من فضلك بقوة / طبيعي يا أخي».  
Kasih harga, dong.  
Iya, dong. (= أكيد)

نبرة لطيفة = ودود. نبرة حادة = تذاكي. ابدأ بلطيف.

### deh
تسليم أو قرار أو عرض نهائي.  
Ya sudah, 40 deh.  
Saya pulang deh.

### sih
تليين أو تذمر خفيف أو «أما عن».  
Mahal sih. (يعني هو غالي…)  
Emang kenapa sih? قد تبدو متضايقة.

افهمها. أنتجها قليلًا بعد أن تقلّد ناطقًا.

### kok
اندهاش أو «ليش».  
Kok mahal? · Kok belum datang?

### kan
أليس كذلك / كما سبق.  
Kan sudah saya bilang. · Enak kan?

### lah / -lah
حسم أو تليين.  
Ya sudah lah. · Pulanglah. (الثانية كتابية/أبوية)

### lho / loh
تنبيه.  
Lho, kok gitu? · Mahal lho.

### nih / tuh
هذا هنا / ذلك هناك.  
Yang ini nih. · Tuh, lihat.

### ah
تذمر. *Ah, males.* قد تبدو صبيانية أو وقحة. لا مع كبار.

### kek
«مثلًا/أي كان». *Bilang kek.* متقدمة عامية.

## 6. كلمات لطيفة مقابل كلمات تجرح

**لطيفة:** ya, silakan, monggo (جاوي مهذب تسمعه)، pelan-pelan, tidak apa-apa, makasih ya, maaf ganggu.

**قد تجرح حسب النبرة:** kamu مع كبير، ah، apaan sih، kagak (نفي جاكرتي خشن)، goblok، anjing، lu مع غريب.

**تبدو لطيفة وهي رفض:** insyaallah، nanti saya kabari، saya pikir dulu، kayaknya susah.

تعلّم قراءة الرفض غير المباشر. لا تضغط.

## 7. اختلاف العمر والمقام

| المقام | ملامح الكلام |
|---|---|
| مع جدّ/موظف حكومة | saya، Pak/Bu، tidak، sudah، جملة كاملة |
| مع زبون | مهذب + يا + سعر واضح |
| مع زميل نفس العمر | udah، nggak، aja، اسمه |
| مع شباب جاكرتا | قد يظهر gue/lu والجسيمات |
| واتساب | اختزال إملائي |
| خطبة/أخبار | baku كامل |

المتعلم الذكي **ينزلق بين سجلّين** لا سجل واحد.

## 8. نطق الشارع — أمثلة كاملة

**كتابي:** Apakah kamu sudah makan?  
**يومي مهذب:** Sudah makan, Pak?  
**عامي:** Udah makan belum?  
**جاكرتي أقران:** Lo udah makan?

تعلّم أن تنتج الثانية، وتفهم الثالثة، وتؤجل الرابعة.

## 9. لاحقة -in العامية

بدل -kan/-i:

bersihin · balikin · masukin · keluarin · beliin · kasih tauin (أحيانًا) · liatin

**الإندونيسية:** Tolong beliin air.  
**طبيعي:** اشتريلي مية لو سمحت.

افهمها من الشهر 2. أنتجها مع أصدقاء من المرحلة 5.
