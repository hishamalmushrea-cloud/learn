# الجزء 6. نظام اللواصق (Affixes)

هذا أعقد باب صرفي في اللغة، وأعلاه عائدًا بعد الكلمات الوظيفية.  
افهمه على طبقات: **وعي → تمييز → إنتاج شائع → إنتاج حر**.

مصادر هذا الباب: شروح Indodic، الدراسات الصرفية لـ *me-*، Tata bahasa baku، واستعمال المتحدثين.

---

## 1. لماذا تتغير الكلمة جذريًا؟

الجذر *buka*:

| الكلمة | البناء | المعنى | نوع |
|---|---|---|---|
| buka | جذر | افتح / يفتح (يومي) | فعل |
| membuka | meN- + buka | يفتح (معلوم رسمي) | فعل |
| dibuka | di- + buka | يُفتح | فعل |
| terbuka | ter- + buka | مفتوح / انفتح | فعل/حالة |
| pembuka | peN- + buka | فاتح / مقدّمة | اسم |
| pembukaan | peN- + buka + -an | افتتاح | اسم |
| bukaan | buka + -an | فتحة | اسم |
| membuka-kan | meN- + buka + -kan | يفتح لشخص | فعل |

جذر واحد، عائلة كاملة. احفظ العائلات لا البطاقات اليتيمة.

---

## 2. الجذر العاري في الكلام الحقيقي

قبل اللواصق: كثير من الأفعال اليومية تُقال بجذرها:

makan, minum, pergi, tidur, duduk, bangun, masuk, keluar, beli, jual, bayar, lihat, dengar, tunggu, coba, pakai, ambil, kasih, minta, buka, tutup

**الإندونيسية:** Saya buka jam sembilan.  
**طبيعي:** أفتح الساعة تسعة.  
رسمي: *Saya membuka toko jam sembilan.*

قاعدة المتعلم: **أنتج الجذر في الكلام، وافهم الملصق في السمع والقراءة.**

---

## 3. meN- — المعلوم النشط

أشيع لاصقة في النصوص (نحو كلمة من كل 13 في بعض إحصاءات Indodic).

### 3.1 المعنى العام
الفاعل يعمل الفعل، وغالبًا يتعدى إلى مفعول: *Dia membaca buku.*

معانٍ أخرى حسب الجذر: عمل الأداة (*mencangkul*)، جمع الشيء، التحول، إلخ. لا تحفظ كل المعاني الآن.

### 3.2 ألومورفات (أشكال) meN-

القاعدة المعتمدة في المراجع التعليمية (مع استثناءات):

| أول الجذر | الشكل | هل يسقط أول حرف؟ | مثال |
|---|---|---|---|
| l, r, w, y, m, n, ny, ng | me- | لا | lihat → melihat · rawat → merawat |
| b, f, v | mem- | لا | baca → membaca · beli → membeli |
| p | mem- | **نعم غالبًا** | potong → memotong · pilih → memilih |
| d, c, j, sy | men- | لا | dengar → mendengar · cari → mencari |
| t | men- | **نعم غالبًا** | tulis → menulis · tolong → menolong |
| s | meny- | **نعم غالبًا** | sewa → menyewa · sapu → menyapu |
| g, h, kh, حروف علة | meng- | لا | ambil → mengambil · hilang → menghilang |
| k | meng- | **نعم غالبًا** | kirim → mengirim · kenal → mengenal |
| جذر مقطع واحد | menge- | لا | bom → mengebom · cek → mengecek · tik → mengetik |

سقوط p/t/s/k هو سبب حيرة المتعلم: *memilih* من *pilih* لا *milih* في الرسمي (أما اليومي فيقول *milih*).

### 3.3 استثناءات تُذكر ولا تُحفَظ كلها الآن
بعض الجذور بـ p لا تسقط (نسب استثناءات ذكرها Indodic). إذا شككت انظر KBBI.

### 3.4 اليومي يخلع meN- ويبقي التحول

menyapu → **nyapu**  
mengerti → **ngerti**  
mengambil → **ngambil**  
mencari → **nyari**  
menulis → أحيانًا *nulis*

هذا أهم من حفظ الجدول للفهم السمعي.

---

## 4. ber-

فعل غالبًا **لازم** (لا يطلب مفعولًا مباشرًا).

معانٍ شائعة:

| المعنى | مثال | طبيعي |
|---|---|---|
| يقوم بنشاط | berjalan, berbicara, belajar | يمشي، يتحدث، يتعلم |
| له / يملك | bernama, beranak, berfungsi | اسمه، له ولد، يعمل/يؤدي وظيفة |
| حالة/صفة | berbahaya, berbeda, bersama | خطر، مختلف، معًا |
| لبس/استخدام | berbaju, bersepatu | لابس قميص/حذاء |
| تبادلي مع -an | bercakapan, berpelukan | يتحادثون، يتعانقون |

أشكال خاصة:

- *bekerja* (لا *berkerja*) — سقوط r أمام عمل يبدأ بـ er في التحليل التقليدي.  
- *belajar* (لا *berajar*).  
- *ber-* + r… قد تُدمج: *berasa* أحيانًا من rasa.

**الإندونيسية:** Nama saya Ahmad. / Saya bernama Ahmad.  
الثانية أكتب قليلًا. اليومية الأولى.

لا تخلط: *belajar* (يتعلم) ≠ *mengajar* (يدرّس).

---

## 5. di- — المجهول

di- + جذر (بدون سقوط حروف meN-):

ambil → diambil (لا *diambil* مع سقوط)  
tulis → ditulis  
kirim → dikirim  
pilih → dipilih

**لا تخلط di- اللاصقة بـ di حرف الجر.**

di rumah = في البيت (حرف، منفصل)  
dirumah خطأ إملائي شائع.  
diambil = يُؤخذ (لاصقة، متصلة)

**الإندونيسية:** Dilarang merokok.  
**طبيعي:** ممنوع التدخين.  
تراه على اللافتات يوميًا.

---

## 6. ter-

| المعنى | مثال | طبيعي |
|---|---|---|
| حالة ناتجة | terbuka, tertulis | مفتوح، مكتوب |
| مصادفة/ involuntary | tertidur, terkejut, tertinggal | غلبه النوم، انفجع، اتسي |
| أقصى درجة | terbesar, terbaik, termahal | الأكبر، الأفضل |
| إمكانية | terdengar, terlihat | يُسمع، يُرى |

*terlalu* = أكثر مما يجب (كلمة جاهزة).  
*terus* ليست من هذه العائلة في الاستعمال (= باستمرار/ثم).

---

## 7. -kan و -i

باب متقدم للإنتاج، مهم للوعي من المرحلة 5.

### 7.1 -kan
غالبًا: اجعل فلانًا يفعل / انقل الفعل إلى مفعول جديد.

bersih → membersihkan = ينظّف (يجعل الشيء نظيفًا)  
ingat → ingatkan = يذكّر  
kirim → kirimkan = أرسلْ (لصالح أحد)

### 7.2 -i
غالبًا: توجيه الفعل نحو مكان أو شخص (محلّي).

datang → mendatangi = يأتي إلى (يزور)  
naik → menaiki = يركب  
sakit → menyakiti = يؤذي

### 7.3 أزواج مربكة (للتقدم)

| -kan | -i |
|---|---|
| menuliskan (يكتب شيئًا لـ) | menulisi (يكتب على سطح) |
| melemparkan | melempari |
| mengirimkan | mengirimi |

لا تنتج الفرق في المرحلة 1–4. افهمه حين تقرأه.

### 7.4 العامية -in
بدلًا من -kan/-i في جاكرتا:

kembalikan → balikin  
bersihkan → bersihin  
kasih tahu → kasih tauin (أحيانًا)

افهمها. إنتاجها اختياري بعد المرحلة 5 في مقام عامي فقط.

---

## 8. -an

يصنع أسماء:

makan → makanan (طعام)  
minum → minuman  
baca → bacaan  
tulis → tulisan  
jual → jualan (بضاعة/بيع متجول)  
kirim → kiriman  
potong → potongan (قطعة/خصم)

شائع جدًا. أولوية إنتاج B.

---

## 9. peN- و peN-…-an

نفس تغيرات meN- تقريبًا:

tulis → penulis (كاتب) → penulisan (كتابة كعملية)  
baca → pembaca → pembacaan  
kirim → pengirim → pengiriman  
jual → penjual → penjualan  
beli → pembeli → pembelian  
ajar → pengajar, pelajar (شاذ نسبيًا: pelajar = طالب)

*pelajar* و*belajar* و*mengajar* و*pengajar* و*pelajaran* عائلة واحدة. احفظها ككتلة.

---

## 10. per-…-an و ke-…-an

**per-…-an:** عملية أو مكان أو مؤسسة  
jalan → perjalanan (رحلة/مسير)  
temu → pertemuan (لقاء)  
toko → pertokoan (منطقة محلات)  
hati → perhatian (انتباه) — غير شفاف؛ احفظه كلمة

**ke-…-an:**  
1. اسم مجرد: baik → kebaikan؛ mampu → kemampuan؛ mungkin → kemungkinan  
2. مصاب بـ: hujan → kehujanan (اتبل من المطر)؛ malam → kemalaman (أدركه الليل)

**الإندونيسية:** Saya kehujanan.  
**طبيعي:** اتبلت من المطر.  
لا تعني «أنا مطر».

---

## 11. se-

| المعنى | مثال |
|---|---|
| واحد + مصنّف | sebuah, seorang, sekilo |
| نفس | seumur, serumah, sekelas |
| أقصى/بقدر | sebesar, sebanyak, sebaiknya |
| كلّ | setiap, semua ( lexikalized) |

*sekali* = جدًا / مرة واحدة حسب الموقع.

Enak sekali. = لذيذ جدًا.  
Sekali saja. = مرة واحدة فقط.

## 12. لواصق أخرى

| اللاصقة | وظيفة | أولوية |
|---|---|---|
| -ku -mu -nya | ملكية | A لـ -nya |
| -lah | تليين أمر/توكيد | B |
| -kah | سؤال رسمي | B |
| -pun | حتى/أيضًا (منفصل غالبًا) | C |
| ke- (عامي) | ke- + صفة أحيانًا: keburu, kegedean | C فهمًا |
| -wan/-wati/-man | دخيل: karyawan, wartawan | C |
| antar- | بين: antarnegara | D |
| tuna- | فاقد: tunanetra | D |
| pra- / pasca- | قبل/بعد | D |

Infix القديمة -el- -er- -em- (*telunjuk, gerigi*) غير منتجة. لا تدرسها للإنتاج.

## 13. كيف تتغير الكلمة «جذريًا» — نماذج تعليمية

### jual
jual · menjual · dijual · terjual · penjual · penjualan · jualan · jual beli

### kerja
kerja · bekerja · mengerjakan · dikerjakan · pekerja · pekerjaan · kerjasama

### ajar
ajar · belajar · mengajar · diajar · pelajar · pengajar · pelajaran · mengajarkan

### beri / kasih
memberi · diberikan · pemberian  
يومي: kasih · dikasih · kasih tau

### lihat
lihat · melihat · dilihat · terlihat · pandangan (غير شفاف تمامًا)  
يومي: liat · liatin

## 14. برنامج تعلم اللواصق (لا تبتلع الجدول يوم 1)

| المرحلة | ماذا تفعل |
|---|---|
| 0–1 | جذور فقط + -nya + se- |
| 2 | تعرّف di- على اللافتات؛ ber- في belajar/bekerja/berbicara |
| 3 | افهم meN- مقابل di- |
| 4 | أنتج di- في الطلب: *tolong dibungkus* |
| 5 | جدول meN- للوعي؛ افهم -an و peN- الشائعة |
| 6 | أنتج meN- في الكلام الأوضح؛ ke-…-an الشائعة |
| 7 | -kan / -i والأخطاء الدقيقة |
| 8 | قراءة حرة تفك العائلات بنفسك |

---

## 15. أخطاء متعلم شائعة

1. *membaca* في السوق بدل *baca* — صحيح لكن متكلف.  
2. خلط *di* المنفصلة بالمتصلة.  
3. نسيان سقوط p/t/s/k عند القراءة (*memilih* يبحث عنها تحت m لا p).  
4. إنتاج *berkerja*. الصحيح *bekerja*.  
5. *Saya kehujanan* تُفهم خطأ «أنا المطر».  
6. لصق meN- على كل شيء: *memakan* صحيحة لكن *makan* أطبيع يوميًا إلا إذا ذكرت المفعول رسميًا.
