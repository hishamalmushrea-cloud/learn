# الجزء 15. الكلمات المتقاربة والمربكة

كل زوج: الفرق + أمثلة حقيقية + ما تقوله أنت.

---

## sudah / telah / belum

*sudah* يومي واسع: اكتمل أو صارت الحالة.  
*telah* رسمي، يسبق فعلًا عادة.  
*belum* لم يحدث بعد (متوقع).

Saya sudah bayar.  
Berita: Pesawat telah mendarat.  
Saya belum bayar. ≠ Saya tidak bayar (رفض/نفي مطلق).

**أنت:** sudah / belum. انسَ telah في السوق.

---

## tidak / bukan / belum / jangan

انظر الجزء 5. خلاصة:  
tidak فعل/صفة · bukan اسم · belum «لسه» · jangan نهي.

---

## mau / ingin / pengen / hendak

mau يومي رغبة أو مستقبل قريب.  
ingin أهدأ وأكتب.  
pengen عامي.  
hendak كتابي/قديم بعض الشيء.

Saya mau ke toilet. (لا ingin هنا؛ تبدو متكلفة)

---

## bisa / dapat / mampu / boleh

bisa قدرة أو إمكانية عملية ★  
dapat قدرة رسمية أو «يحصل على»  
mampu قدرة حقيقية/مالية  
boleh إذن

Saya tidak bisa datang. مش هأقدر أحضر.  
Saya tidak boleh datang. مش مسموح لي.  
Saya tidak mampu bayar. مش قادر أدفع (فلوس).

---

## lihat / melihat / lihatlah / liat / kelihatan

lihat جذر يومي.  
melihat معلوم رسمي.  
lihatlah أمر كتابي.  
liat نطق/كتابة يومية.  
kelihatan يبدو/يُرى: *Kelihatan mahal.*

أنت: lihat / liat / coba lihat.

---

## tahu / kenal

tahu معلومة. kenal شخص/شيء بألفة.

Saya tahu namanya, tapi belum kenal.  
أعرف اسمه بس لسه ما اتعرفنا.

---

## pergi / berangkat / jalan

pergi يذهب عام.  
berangkat ينطلق (رحلة/دوام).  
jalan يمشي أو «يمشي حاله».

Jam berapa berangkat? لموعد قطار أفضل من pergi.

---

## pulang / kembali / balik

pulang إلى البيت/الأصل.  
kembali يعود/يُعاد.  
balik يومي جدًا: يرجع/ينقلب.

Saya pulang. هأرجع البيت.  
Saya balik lagi besok. هأرجع تاني بكرة.  
Kembalian الباقي.

---

## datang / tiba / sampai

datang يأتي شخص/شيء.  
tiba وصول رسمي لمركبة غالبًا.  
sampai يصل/حتى.

Saya sudah sampai. وصلت (واتساب ★).

---

## bilang / berkata / mengatakan / ngomong

bilang يومي ★  
ngomong يتكلم

---

## kasih / beri / memberikan

kasih يومي ★

Saya kasih 40.

---

## bikin / buat / membuat

bikin يومي. buat يومي أيضًا (و«لأجل»). membuat رسمي.

Siapa yang bikin ini?

---

## kerja / bekerja / kerjakan

kerja اسم أو فعل يومي.  
bekerja فعل ber-.  
kerjakan = أنجز العمل (متعدٍ).

Saya kerja di pasar.  
Kerjakan dulu yang ini. خلّص ده الأول.

---

## tinggal / hidup / diam

tinggal يسكن/يبقى.  
hidup يعيش.  
diam يسكت/ساكن.

Saya tinggal di Surabaya.  
Jangan diam saja. متسكتش.

---

## lama / tua / lambat

lama مدة طويلة أو قديم استعمال.  
tua عمر.  
lambat بطيء.

Antriannya lama. الطابور طول.  
Orangnya tua.  
Kerjanya lambat.

---

## baru / muda / baru saja

baru جديد/للتوكيد «ما إن».  
muda صغير سن.  
baru saja للتو.

Saya baru datang. لسه واصل.  
Dia masih muda.

---

## jam / waktu / jam (ساعة يد)

waktu وقت عام.  
jam الساعة العددية أو ساعة اليد.  
pukul رسمي للساعة: *pukul 07.00*

Jam berapa?  
Waktunya tidak cukup.

## harga / bayar / biaya / ongkos / ongkir

harga سعر السلعة.  
bayar فعل الدفع.  
biaya تكلفة عامة.  
ongkos أجرة.  
ongkir أجرة شحن (اختصار ongkos kirim).

## ramai / macet / penuh

ramai ناس وزحمة حيوية.  
macet سيارات لا تسير.  
penuh ممتلئ.

Pasarnya ramai.  
Jalannya macet.  
Toko penuh.

---

## enak / bagus / baik / lucu

enak لذة حسّية أو راحة.  
bagus جودة.  
baik أخلاق/حال.  
lucu مضحك أو كيوت.

Orangnya baik.  
Barangnya bagus.  
Masakannya enak.  
Anaknya lucu.

---

## coba / tes / periksa / cek

coba جرّب ★  
cek افحص يومي  
periksa يفحص (طبيب/رسمي)  
tes اختبار

Coba dulu.  
Cek stok.  
Periksa ke dokter.

## tanya / minta / minta tolong

tanya يسأل معلومة.  
minta يطلب شيئًا.  
minta tolong يطلب مساعدة.

Mau tanya harganya.  
Minta notanya.  
Minta tolong beliin air.

## karena / soalnya / makanya / jadi

Mahal soalnya bahannya bagus.  
Makanya saya nggak ambil.

## kalau / jika / pas / waktu

kalau إذا/لما يومي ★

## di (جر) / di- (مجهول)

sangat توكيد لا تفضيل.
