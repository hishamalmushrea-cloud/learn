# الجزء 4. الضمائر والمخاطبة والألقاب الاجتماعية

هذا الباب **اجتماعي قبل أن يكون نحويًا**. الخطأ فيه يُفهم على أنه وقاحة، لا على أنه خطأ قواعد.

---

## 1. المبدأ الذي لا يتنازل عنه

في العربية تقول «أنت» للجميع تقريبًا مع اختلاف اللهجة.  
في الإندونيسية، **ضمير المخاطب فخ**. المتحدث الأصلي كثيرًا ما يقول:

**الإندونيسية:** Bapak mau yang ini?  
**النطق:** باپاْك ماوْ يانْغ إيْني  
**طبيعي:** حضرتك تريد هذا؟  
**حرفي:** أب يريد الذي هذا.  
**استخدام:** بدل *Anda/kamu mau yang ini?*  
**سجل:** يومي مهذب. A

أو يستخدم الاسم:

Andi sudah makan?

**قاعدة المتعلم:**  
إذا شككت، قل **اللقب ± الاسم**، ولا تقل *kamu*.

## 2. ضمائر المتكلم

### 2.1 saya ★ اختيارك الافتراضي

| | |
|---|---|
| المعنى | أنا |
| النطق | سايَا |
| السجل | مهذب، محايد، صالح لكل مقام تقريبًا |
| الشيوع | A — الأعلى أمانًا للأجنبي |

**الإندونيسية:** Saya mau beli ini, Bu.  
**طبيعي:** أريد شراء هذا، أستاذة.  
**سجل:** يومي مهذب.

يُستخدم في الأخبار، والمتجر، والعمل، ومع الغرباء، ومع الأكبر سنًا.  
بعض الشباب يراه «رسميًا زيادة» بين الأصدقاء؛ هذا لا يعني أنه خطأ.

### 2.2 aku

| | |
|---|---|
| المعنى | أنا |
| النطق | أَكُو |
| السجل | حميمي: أصدقاء، عائلة، حب، أغاني، يوميات |
| الخطر | مع غريب أكبر منك قد يبدو تطاولًا |

**الإندونيسية:** Aku kangen kamu.  
**طبيعي:** اشتقت لك.  
**سجل:** حميمي. لا تُقال لبائع.

متى تنتقل من *saya* إلى *aku*؟  
عندما يبادلك الطرف *aku*، أو يطلب منك عدم التكلف، أو تكونان في عمر متقارب وصداقة واضحة.

### 2.3 gue / gua / gw

| | |
|---|---|
| الأصل | بيتاوي / جاكرتا |
| المعنى | أنا |
| السجل | عامي جاكرتي، أقران |
| حكم المتعلم | **لا تنتجها في السنة الأولى** إلا داخل عصبة جاكرتية تستخدمها معك |

**الإندونيسية:** Gue lagi gabut.  
**طبيعي:** قاعد زهقان/فاضي.  
**سجل:** شبابي جاكرتي.

خلاف حقيقي: في باندونغ ومدن أخرى قد تُعد *gue/lu* وقحة. في جاكرتا بين الشباب عادية. لا تعمّم.

### 2.4 kami ≠ kita

هذا الفرق معياري ومهم، ويخطئ فيه حتى بعض الإندونيسيين في الكلام السريع.

| | kami | kita |
|---|---|---|
| المعنى | نحن **دونك** | نحن **وأنت** |
| مثال | Kami dari toko ini. | Kita makan dulu, yuk. |
| طبيعي | نحن (فريقنا) من هذا المحل. | تعال نأكل. |
| متى | تقديم مجموعة لخارجها | اقتراح مشترك، حديث يجمعكما |

**خطأ شائع:** استعمال *kita* وأنت تقصد فريقك فقط أمام زبون.  
في السوق إذا قدّمت محلّك: *Kami punya stok baru.*  
إذا دعوت الزبون: *Kita coba yang ini, yuk.*

هناك «kita الملكية» في بعض الأساليب القديمة/السلطانية؛ تجاهلها الآن.

## 3. ضمائر المخاطب

### 3.1 Anda

رسمي، شائع في الكتابة، والإعلانات، والنماذج، وخدمة العملاء الهاتفية.

**الإندونيسية:** Apakah Anda sudah punya rekening?  
**طبيعي:** هل لديك حساب بنكي؟  
**سجل:** رسمي.

في الكلام الحي بين شخصين، *Anda* قد يبدو باردًا أو «مترجَمًا». الناس يفضّلون *Pak/Bu*.

### 3.2 kamu

غير رسمي. مقبول مع:

- أصغر منك بوضوح  
- صديق مقرّب  
- طفل  
- زميل بنفس العمر بعد أُلفة

غير مقبول عادة مع:

- بائع أكبر  
- والد صديق  
- مدير  
- زبون لا تعرفه  
- شرطي/موظف

**الإندونيسية:** Kamu mau ke mana?  
بين صديقين = «رايح فين؟»  
مع غريب أكبر = نبرة قد تُفهم كأنها «انت مين».

### 3.3 kau / engkau

شعري، ديني، أدبي، أغاني.  
*Engkau* في الدعاء: *Ya Allah, Engkau…*  
لا تقل *kau* لبائع. قد تبدو قديمة أو فظة حسب النبرة.

### 3.4 kalian

أنتم (غير رسمي إلى محايد).  
رسمي الجمع: *Anda sekalian* / *Bapak-Ibu sekalian*.

### 3.5 الاستبدال الاجتماعي — الجدول الذهبي

| المقام | ماذا تقول بدل «أنت» |
|---|---|
| رجل بالغ / محترم / 30+ تقريبًا | Pak / Bapak / Pak + اسم |
| امرأة بالغة | Bu / Ibu / Bu + اسم |
| شاب في مدينة جاوية/كبرى | Mas |
| شابة في مدينة جاوية/كبرى | Mbak |
| عمر قريب، جنس غير واضح أو تردد | Kak |
| طفل | Dik / Nak / الاسم |
| زبون | Pak/Bu + نبرة لطيفة |
| مدير | Pak/Bu + اسم، أبدًا kamu |
| مجموعة رسمية | Bapak-Ibu |
| صديق حميم | الاسم أو kamu |

## 4. الألقاب بالتفصيل

### 4.1 Pak / Bapak و Bu / Ibu

من «أب» و«أم»، لكنهما لقبان عامّان للاحترام، ليسا نسبًا.

**الإندونيسية:** Permisi, Bu, ini berapa?  
**طبيعي:** لو سمحتِ أستاذة، بكم هذا؟

يُختصران نطقًا: Pak, Bu.  
*Bapak* كاملة أكثر رسمية أو عند النداء من بعيد.

يُستعملان حتى مع غير المتزوجين إذا بدا الشخص بالغًا. لا تسأل أولًا «متزوجة؟» لتختار اللقب.

### 4.2 Mas / Mbak

أصل جاوي: «أخ أكبر» / «أخت أكبر».  
انتشر في المدن، خاصة جاوة وجاكرتا، للمخاطبة اليومية مع الشباب والموظفين في المطاعم والمحلات.

**الإندونيسية:** Mbak, minta nasi goreng satu, tidak pedas.  
**طبيعي:** آنسة، رز مقلي واحد، من غير حار.

خلاف: خارج جاوة قد يُفضَّل *Kak*. في سومطرة الغربية ألقاب أخرى (مثل *Uni, Uda* في السياق المينانغكابوي — إقليمي، لا تتعلمه للإنتاج العام).

### 4.3 Kak / Kakak

محايد الجنس، من «أخ/أخت أكبر».  
آمن جدًا مع عمر قريب في الخدمة والمدرسة والمحادثات اللطيفة.

### 4.4 Dik / Adik

للأصغر. لطيف مع طفل أو بائع صغير جدًا. مع بالغ قد يبدو تنازلًا.

### 4.5 Bang / Abang

«أخ أكبر» شائع في جاكرتا/بيتاوي/سومطرة لبعض السياقات (سائق أوجيك: *Bang*).  
*Ngab* مقلوب شبابي لـ *Bang*. لا تبدأ به.

### 4.6 Om / Tante

من الهولندية. لرجل/امرأة أكبر في سياق حضري عائلي أو جيران. أقل رسمية من Pak/Bu أحيانًا، وأكثر أُلفة.

### 4.7 ألقاب أخرى تسمعها

| اللقب | المعنى/السياق | إنتاجك |
|---|---|---|
| Bro / Sis / guys | شبابي إنجليزي | لا لزوم |
| Bos | يا كبير (مزاح أو زبون) | افهم |
| Juragan | صاحب محل قديم/مزاح | افهم |
| Neng | فتاة سوندانية/بعض جاوة | إقليمي |
| Yu / Mbakyu | جاوي | إقليمي |
| Ustadz/Ustadzah | ديني | إذا ناسب |
| Habib | سياق ديني معيّن | لا تتوسع |
| Saudara/i | رسمي جدًا، مقابلات | نادر يوميًا |

### 4.8 متى تستخدم كل واحدة؟ قرار سريع

```
هل يبدو أكبر منك بوضوح أو في موقع رسمي؟ → Pak / Bu
هل هو شاب/شابة يخدمك في مطعم/محل بجاوة أو مدينة كبرى؟ → Mas / Mbak
هل ترددت؟ → Kak أو Pak/Bu (الأأمن)
هل صديق حميم؟ → الاسم / kamu
```

الأجنبي الذي يقول *Pak/Bu* زيادة يُحَب.  
الأجنبي الذي يقول *kamu* زيادة يُحتمل بصبر أو يُعدّ فظًا.

## 5. ضمائر الغائب

### 5.1 dia

هو أو هي. لا جنس.

**الإندونيسية:** Dia sudah pulang.  
**طبيعي:** رجع / رجعت. السياق يحدد.

### 5.2 ia

نفس المعنى في الكتابة الرسمية. نادر في الكلام.

### 5.3 beliau

تبجيلي.

**الإندونيسية:** Beliau sedang rapat.  
**طبيعي:** سيادته/حضرتها في اجتماع.  
للرئيس، العالم، والد صاحبك، شخص محترم غائب.

### 5.4 mereka

هم / هن. لا جنس.

### 5.5 الاسم بدل الضمير

شائع جدًا لتفادي الغموض أو للّطف:

Ibu Sari belum datang. (لا *Dia belum datang* إن كان أوضح)

## 6. الملكية

ثلاث طبقات:

1. **اسم + ضمير:** rumah saya, nama kamu, HP dia  
2. **لاحقة:** rumahku, namamu, HP-nya  
3. **punya:** Saya punya dua anak. / Ini punya saya.

| الشكل | سجل | ملاحظة |
|---|---|---|
| rumah saya | مهذب آمن | ★ للمتعلم |
| rumahku | حميمي/كتابي خفيف | مع aku |
| rumahmu | مع kamu فقط | لا مع Pak |
| rumahnya | بيته/البيت المقصود | -nya متعددة الوظائف |
| punya saya | يومي | توكيد الملكية |

**الإندونيسية:** Ini HP-nya siapa?  
**طبيعي:** تليفون مين هذا؟  
*-nya* هنا تقريبًا «الـ» + ربط.

لا تقل *rumah Anda* طوال الوقت وأنت واقف أمام الرجل؛ قل *rumah Bapak*.

## 7. أسئلة شخصية حساسة

الإندونيسيون قد يسألون مبكرًا:

Sudah menikah?  
Sudah punya anak?  
Kerjanya apa?  
Orangnya mana? (أصلك من وين)

هذه قد تكون فضولًا ودودًا لا تحقيقًا.  
ردّ خفيف:

Belum, Pak.  
Sudah.  
Saya kerja jualan.  
Saya dari… 

يحق لك أن تبتسم وتختصر. لا يلزمك تفصيل راتبك.

## 9. تمارين مقام

حوّل الجملة حسب الشخص:

أصل: Mau beli apa?

- لزبون رجل كبير: *Bapak mau beli apa?*  
- لبائعة شابة: *Mbak, saya mau tanya, ini ada ukuran L?*  
- لصديق: *Kamu mau beli apa?*  
- لمجموعة زبائن: *Mau lihat-lihat dulu, Pak, Bu?*

درّب هذا التحويل يوميًا؛ هو أهم من حفظ 50 ضميرًا نادرًا.
