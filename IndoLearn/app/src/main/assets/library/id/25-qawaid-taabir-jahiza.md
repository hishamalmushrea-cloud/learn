## 10. كيف تولّد المزيد

خذ قالبًا وبدّل عنصرًا:

Saya mau + [اسم].  
Ada + [اسم] + nggak?  
Boleh minta + [اسم]?  
Yang ini + [صفة].  
Kalau + [شرط], saya + [فعل].

هذا يولّد مئات الجمل من دون قائمة مغلقة.  
كل جملة جديدة تسمعها في السوق: اكتبها هنا في نسختك الشخصية مع السجل والتاريخ.
