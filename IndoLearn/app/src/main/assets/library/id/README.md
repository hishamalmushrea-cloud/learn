# الموسوعة العملية الشاملة لتعلم Bahasa Indonesia

**للناطق بالعربية · من الصفر إلى الطلاقة العملية**

هذه ليست قائمة دروس، وليست خطة عامة. هذه **موسوعة تعليمية + منهج دراسي + قاعدة لغوية + دليل حياة يومية وتجارة**، مبنية على مصادر رسمية إندونيسية (BIPA / Badan Bahasa / KBBI / UKBI) ومصادر أكاديمية ومتحدثين أصليين، مع تمييز صريح بين:

| الطبقة | الاسم الإندونيسي | متى تُستخدم |
|---|---|---|
| اللغة القياسية الرسمية | Bahasa Indonesia baku / resmi | الأخبار، المعاملات، الدراسة، العمل الرسمي |
| اللغة اليومية المهذبة | Bahasa sehari-hari sopan | معظم حياة الأجنبي الناجح |
| العامية الحضرية | Bahasa informal / percakapan | الأصدقاء، السوق، واتساب |
| عامية الشباب / الجاكرتية | Bahasa gaul / dialek Jakarta | الشباب، الميديا، جاكرتا |
| اللغات الإقليمية | Jawa, Sunda, Betawi, dll. | ليست إندونيسية؛ تُسمع كثيرًا لكن تُؤجَّل |

**القاعدة الذهبية لهذه الموسوعة:**  
الهدف ليس «أن تعرف القواعد»، بل:

> أن تسمع الإندونيسي، وتفهم ما يريد، وتردّ عليه بطريقة طبيعية ومفهومة ومحترمة.

## كيف تقرأ هذه الموسوعة

1. ابدأ بـ [00-كيفية-استخدام-الموسوعة](00-kaifa-tastakhdim.md).
2. اقرأ [01-الخريطة-الكبرى](01-al-kharita-al-kubra.md) كاملة قبل أي حفظ مفردات.
3. اتبع [02-المنهج-المتدرج](02-al-manhaj.md) بالترتيب، لا بالقفز.
4. استخدم بقية الأجزاء كمرجع حيّ أثناء التدريب اليومي.

كل مثال تعليمي يتبع هذا القالب كلما أمكن:

**الإندونيسية:** …  
**النطق بالعربية (تقريبي):** …  
**الترجمة العربية الطبيعية:** …  
**الترجمة كلمة بكلمة:** …  
**شرح الاستخدام:** …  
**ملاحظة السجل:** رسمي / يومي / عامي / شبابي / تجاري / إقليمي

النطق العربي **وسيلة مساعدة فقط**. الأصوات `ng` و`ny` و`e-pepet` و`c` لا تُمثَّل بدقة بالحروف العربية.

## مبدأ الجودة

كل معلومة في هذه الموسوعة خضعت لهذه الأسئلة:

1. هل هي صحيحة وفق مصادر إندونيسية موثوقة؟
2. هل هي شائعة في الكلام الحقيقي؟
3. هل هي مفيدة لمتعلم عربي هدفه التواصل العملي؟
4. هل هي في المستوى المناسب؟
5. هل هناك فرق بين الرسمي واليومي؟
6. هل هناك تعبير أكثر طبيعية؟

إذا كانت الكلمة نادرة أو إقليمية أو قديمة، يُذكر ذلك صراحة.  
لا تُخترع أمثلة. إذا وُجد خلاف بين المصادر، يُذكر الخلاف.
