# IndoLearn — نظام تعلّم لغات للناطقين بالعربية

تطبيق Android لتعليم **الإندونيسية** و**التركية** للعرب، من الصفر إلى الاستخدام اليومي.

> **كل رقم في هذا الملف مُستخرج آلياً من الكود عبر `tools/validate_seed.py`.**
> إذا عدّلت المحتوى، أعد تشغيل `./tools/verify_all.sh` وحدّث الأرقام.

## المكتبة المرجعية (موسوعتان)

| اللغة | المصدر | الملفات |
|---|---|---|
| 🇮🇩 | [indolang](https://github.com/hishamalmushrea-cloud/indolang) `arena/019ff99f-indolang` | 27 |
| 🇹🇷 | [turklang](https://github.com/hishamalmushrea-cloud/turklang) `arena/019ff9c0-turklang` | 6 |

المكتبة **تتبع اللغة المختارة**: `assets/library/id/` و`assets/library/tr/`.

الدمج على **طبقتين**، بلا فقدان أي محتوى:

| الطبقة | ماذا | أين |
|---|---|---|
| مرجع كامل | 34 ملف Markdown كما هي (تشمل فهرس الإندونيسية) | `assets/library/{id,tr}/` ← شاشة «المكتبة المرجعية» |
| محتوى قابل للتعلم (ID) | 187 عبارة + 63 سؤال سجل | `IndoLangContent.kt` |
| محتوى قابل للتعلم (TR) | 127 تعبيراً + 23 سؤالاً + 49 حواراً | `TurkLangContent.kt` |

**التركية ليست نسخة من منهج الإندونيسية.** المستورد التركي منفصل لأن المصدر
يحمل بنية مختلفة: سلّم سجل رباعي (رسمي · محايد · يومي · عامي)، وجداول
«مدرسي مقابل طبيعي»، وتحذيرات اجتماعية صريحة (`moruk` قد تُهين، `lan` غير مهني).
هذه الفروق تولّد أنواع أسئلة لا وجود لها في الجانب الإندونيسي.

**لماذا طبقتان؟** كثير من المحتوى شرح نثري وسياق ثقافي وتحذيرات استخدام؛
تفكيكه قسراً إلى صفوف قاعدة بيانات يُفقده معناه. لذلك يُعرض كاملاً كمرجع،
بينما تُستخرج الصفوف المنتظمة فقط لتدخل التكرار المتباعد والاختبارات.

الاستخراج **محافظ ومُتحقَّق منه**: يُرفض أي صف بلا ترجمة عربية،
ويُدمج المكرر بدل رفضه، ولا يُستورد ما هو موجود أصلاً في البذر اليدوي.

لإعادة التوليد بعد تعديل المصدر:

```bash
python3 tools/import_indolang.py --emit   # يولّد IndoLangContent.kt
python3 tools/import_turklang.py --emit   # يولّد TurkLangContent.kt
```

> ⚠️ `IndoLangContent.kt` و`TurkLangContent.kt` **مُولَّدان آلياً** — لا تحررهما يدوياً.

## البنية

```
app/src/main/java/com/indolearn/
├── domain/              ← Kotlin نقي، بلا اعتماد على Android (قابل للاختبار)
│   ├── srs/             ← محرك التكرار المتباعد (SM-2 معدّل)
│   ├── coach/           ← المدرب اليومي والتعلّم التكيّفي
│   └── quiz/            ← تقييم إجابات متعدد اللغات بلا نجاحات زائفة
├── data/
│   ├── local/           ← Room: 15 كياناً، 14 DAO، ترحيلان 4→5→6
│   ├── library/         ← قارئ الموسوعتين + محلل Markdown (أوفلاين)
│   └── repository/      ← LearnRepository + IndoLangContent + TurkLangContent
├── ui/screens/          ← 27 ملف شاشة Compose
├── viewmodel/           ← 3 ViewModels
├── navigation/
└── utils/
```

**لماذا `domain/` منفصل:** ليكون منطق التعلّم قابلاً للاختبار والتشغيل
بلا محاكي — وهو ما مكّن من تنفيذ 32 اختباراً مستقلاً سريعاً، إضافة إلى
اختبارات Gradle الفعلية في GitHub Actions.

## محرك التعلّم

- **التكرار المتباعد:** SM-2 معدّل. الفواصل 1 ← 6 ← تصاعدي، بحد أقصى سنة.
  العنصر الفاشل يُعاد **داخل الجلسة** (بعد 10 دقائق) لا بعد يوم كامل.
- **حالات الإتقان:** `NEW → LEARNING → WEAK → FORGOTTEN → MASTERED`
  محسوبة من الأداء، لا مخزَّنة يدوياً (فلا يمكن أن تتناقض مع البيانات).
- **المدرب اليومي:** يرتّب الأولويات: المنسي ← الضعيف ← المستحق ← درس جديد ← سيناريو.
  ويمنع الدروس الجديدة عند تراكم ديون المراجعة، مع شرح السبب للمستخدم بالعربية.
- **التثبيت التكيفي للأخطاء:** يحفظ كل محاولة سؤال، ويجدول الخطأ للغد ثم يوسّع
  الفواصل بعد النجاح إلى 3 ← 7 ← 14 يوماً. يختار المدرب 5 نقاط كحد أقصى،
  ويحافظ على نوع العنصر كي لا تُعرض الأسئلة كبطاقات مفردات.

## التحقق

```bash
./tools/verify_all.sh          # كل البوابات
./tools/run_engine_spec.sh     # اختبارات محرك التعلم فقط (تنفيذ فعلي)
./tools/run_markdown_spec.sh   # اختبار محلل الموسوعة (تنفيذ فعلي)
python3 tools/validate_seed.py # سلامة المحتوى
```

لتشغيل بوابة الاختبارات تحتاج JDK وKotlin (يُثبَّتان من قنوات غير محجوبة):

```bash
python3 -m venv /tmp/jvenv && /tmp/jvenv/bin/pip install jdk4py
mkdir -p /tmp/kt && cd /tmp/kt && npm install kotlin-compiler@2.2.20
```

> `kotlin-compiler@2.0.21` (إصدار المشروع) **يفشل على JDK 25**
> بخطأ `IllegalArgumentException: 25.0.2`. استخدم 2.2.20 أو JDK 17.

## الفتح والبناء

1. افتح **Android Studio** (Hedgehog أو أحدث).
2. `File → Open` واختر مجلد `IndoLearn`.
3. انتظر Gradle Sync (يحتاج إنترنت غير محجوب).
4. `Run`.

## إضافة محتوى

المحتوى مبذور في `LearnRepository.seedInitialData()`.
**بعد أي إضافة شغّل `./tools/verify_all.sh`** — ستلتقط البوابات:
عدد وسائط خاطئ، مفتاحاً مكرراً، درساً بلا تفاصيل، إجابة خارج الخيارات،
أو تسرّب كلمة بين اللغات. (كل هذه الأنواع وُجدت فعلاً في الكود سابقاً.)
